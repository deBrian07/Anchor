# Voiceover (~150 wpm, ~3:00)

Read this in one take if you can. Pause on the demo so the UI can play.

---

You're still at the ruins. All aboard is in twelve minutes. The ship does not wait.

Every sailing, someone is late ashore. The port is loud, the pier is far, and the only plan is a panicked call that nobody answers. Then the ship leaves.

Rejoin is a text bot for that passenger. You text that you are still ashore. It starts the clock, puts you on the map, and gives you one tap to call the port agent.

The thread is the product. Text sample to load a mock sailing. Text that you are still at the ruins. Skip the clock to after all aboard. Call.

There is no iMessage server in this build. A local API runs the clock and the map. If send is ever wired, it can only reach numbers on an allowlist, and only after that number texts first in the same session.

You do not install an app in port. You already know how to text.

Rejoin. Still ashore. Ship's leaving. One text to get back.
